# Ahmeds Builder Page

Ahmeds Builder Page is a personal builder website that I made from scratch using HTML5 and CSS.

## Features

- Ahmeds Builder Page has a bio and a list of hobbies such as ESP32 electronics, Assetto Corsa and Football.

- Ahmeds Builder Page displays HTML5 skill progress bars.

- Ahmeds Builder Page includes embedded audio and video players.

- Ahmeds Builder Page contains a weekly schedule table.

- Ahmeds Builder Page has a collapsible secret fact section using `<details>`.

- Ahmeds Builder Page features a visitor message form.
